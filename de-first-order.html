First Order
System Dynamics

dy/dx + P(x)y = Q(x)
Definition

What is a First-Order D.E?

A first-order differential equation contains only the first derivative of the dependent variable. It describes how a quantity changes at every instant, making it ideal for modeling dynamic systems.

First-order D.E.s are used across engineering, robotics, automation, electrical circuits, population growth, cooling systems, and chemical reactions — wherever a rate of change depends on current state.

General Form
dy/dx + P(x)y = Q(x)
y= dependent variable
x= independent variable
P(x), Q(x)= functions of x
Classification

Static vs Dynamic Systems

Understanding the difference between memory-less and memory systems

💡 Static System

Output depends on
present input only

A static system responds instantly to its input with no dependence on history. Remove the input, and the output immediately disappears.

Example
Light bulb brightness depends directly on the switch position — instant on/off.
🌀 Dynamic System

Output depends on present & past inputs

A dynamic system has memory. Stored energy or state means the system continues to respond even after the input is removed.

Example
A fan continues spinning after power is cut — kinetic energy is stored in the rotating blades.

Positive Feedback

Amplifies Response

Increases system response by adding the fed-back signal to the input. Can cause exponential growth and potentially unstable behavior.

Microphone squeal Population explosion Chain reactions
Negative Feedback ★ Preferred

Opposes Change

Subtracts the fed-back signal from the input, opposing deviations. This improves stability and accuracy. Used in virtually all engineering control systems.

Air conditioner Thermostat Cruise control Op-amp circuits
Real-World Application

Cooling Curve & Newton's Law

First-order dynamic behavior in thermal systems

The cooling of a hot object follows a first-order differential equation — one of the most elegant examples of exponential decay in nature.

Newton's Law of Cooling
dT/dt = −k(T − Ts)
T= Temperature of object at time t
Ts= Surrounding (ambient) temperature
k= Cooling constant (k > 0)
  • Temperature starts at a high initial value
  • Decreases rapidly at first (large temperature difference)
  • Cooling rate gradually slows as gap narrows
  • Temperature asymptotically approaches room temperature

This behavior is called exponential decay.

Direction Fields

A graphical method to visualize solutions without solving them completely

A direction field (or slope field) draws tiny line segments at every point (x, y) showing the slope dy/dx predicted by the differential equation — without needing to solve it.

For dy/dx = x + y, we compute slopes at sample points:

Point (x, y) Calculation Slope
(0, 0)0 + 00
(1, 0)1 + 01
(0, 1)0 + 11
(1, 1)1 + 12
(-1, 1)-1 + 10
(2, -1)2 + (-1)1

→ Solution rises
