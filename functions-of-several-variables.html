Introduction

Functions of Two Variables

Quantities depending on more than one variable — describing surfaces in three-dimensional space

Definition
z = f(x, y)
x, y= independent variables
z= dependent variable (output)
f= rule assigning unique z to every pair (x,y)

Unlike ordinary functions, these describe surfaces in 3D space — the foundation of engineering, robotics, machine learning, and optimization.

Worked Example
Example: z = x² + y²
For x = 1, y = 2
z= 1² + 2² = 5

This graph forms a paraboloid — a bowl-shaped surface. Minimum value occurs at the origin; surface rises in all directions. Used widely in optimization problems.

Limits & Continuity

Approaching a Point

A limit describes the value approached by f(x,y) as (x,y) → (a,b) from any direction

Limit & Continuity Check

f(x,y) = x² + y²
Limit
// Find limit at (0,0)
lim (x,y)→(0,0) (x²+y²)
= 0² + 0² = 0
Check
// Continuity condition
lim f(x,y) = f(a,b)
0 = f(0,0) = 0 ✓
Result
// Conclusion
Function is continuous at (0,0)
Continuous everywhere on ℝ²
Importance of Limits
  • ·Determining continuity of a surface
  • ·Establishing stability of systems
  • ·Smoothness of physical models
  • ·Physical feasibility verification
Classification

Key Concepts

Level curves, partial derivatives, gradient vector — the tools of multivariable calculus

Level Curves

Constant Value Contours

f(x,y) = C (constant)
  • Set z = C to get curve in xy-plane
  • z = x²+y²; C=1 → circle of radius 1
  • Analogous to topographic map contours
  • Used in pressure & temperature analysis
Partial Derivatives

Rate of Change

∂z/∂x and ∂z/∂y
  • Differentiate w.r.t. one variable, hold others fixed
  • For z=x²+y²: ∂z/∂x=2x, ∂z/∂y=2y
  • At (1,2): ∂z/∂x=2, ∂z/∂y=4
  • Faster change in y-direction at (1,2)
Gradient Vector

Direction of Max Increase

∇f = (∂f/∂x)i + (∂f/∂y)j
  • Combines all partial derivatives into a vector
  • At (1,2): ∇f = 2i + 4j
  • Points toward steepest ascent
  • Always perpendicular to level curves

Optimization

Maxima, Minima & Saddle Points

Critical points where ∂f/∂x = 0 and ∂f/∂y = 0 simultaneously

Finding Critical Points

f(x,y) = x² + y²
Step 1
// Set partial derivatives to zero
∂f/∂x = 2x = 0 → x = 0
∂f/∂y = 2y = 0 → y = 0
Step 2
// Critical point found
Critical point: (0, 0)
Result
// Evaluate at critical point
f(0,0) = 0 → Global Minimum
Minimum at (0,0) with f = 0

Saddle Point Example

f(x,y) = x² − y²
Step 1
// Set partial derivatives to zero
∂f/∂x = 2x = 0 → x = 0
∂f/∂y = −2y = 0 → y = 0
Step 2
// Analyse behaviour
Along x-axis: f increases
Along y-axis: f decreases
Result
// Not max, not min
Point (0,0) is a Saddle Point
Saddle Point at origin — neither max nor min
Constrained Optimization

Lagrange Multipliers

Optimize f(x,y) subject to a constraint g(x,y) = 0 using ∇f = λ∇g

Lagrange Example

Maximize f = xy, subject to x+y=10
Setup
// Define objective & constraint
f(x,y) = xy
g(x,y) = x + y − 10 = 0
Condition
// Apply ∇f = λ∇g
∂f/∂x = y = λ · 1
∂f/∂y = x = λ · 1
Therefore: x = y
Solve
// Use constraint
x + y = 10 and x = y
→ x = 5, y = 5
Maximum f = 5 × 5 = 25 at (5, 5)

Conclusion

Functions of several variables extend single-variable calculus into the multidimensional world — the mathematical reality of engineering systems.

Partial derivatives, gradient vectors, level curves, and Lagrange multipliers form a powerful toolkit for analysing and optimizing real-world systems: from robot trajectories to heat distribution, from machine learning loss surfaces to structural design.
