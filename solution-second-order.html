Chapter 04 · Numerical Methods

Solution for Second Order
Differential Equations

d²y/dx² = −y,   y(0) = 1
Overview

Numerical Methods

Many higher-order DEs cannot be solved analytically — numerical methods provide iterative approximations

Problem Statement
d²y/dx² = −y
y(0)= 1 (initial displacement)
y'(0)= 0 (initial velocity)
h= 0.1 (step size)

Convert to two first-order equations by letting z = dy/dx:

// System of first-order equations
dy/dx = z
dz/dx = −y

// Initial conditions
y₀ = 1    z₀ = 0

Stable Method

Errors remain bounded throughout computation. Results converge and remain accurate regardless of the number of iterations performed.

Unstable Method

Errors grow with each iteration. Results diverge from the true solution and become unreliable over successive steps.

Exact Analytical Solution

The equation d²y/dx² = −y has the exact solution:

y = cos(x)

At x = 0.1:   y = cos(0.1) ≈ 0.995004

Methods

Comparing the Three Approaches

Euler → Heun/Midpoint → RK4: increasing accuracy at each level

Euler

Simplest Approximation

yₙ₊₁ = yₙ + h·zₙ
zₙ₊₁ = zₙ + h·(−yₙ)
  • First-order accurate
  • Single slope evaluation
  • Quickest to compute
  • Least accurate result
y(0.1) = 1.0000  |  Error: 0.005
Heun / Midpoint

Predictor-Corrector

y* = y₀ + h·z₀
y₁ = y₀ + h/2·(z₀+z*)
  • Second-order accurate
  • Two slope evaluations
  • Predictor then corrector
  • Significantly improved
y(0.1) = 0.9950  |  Error: 0.000004
RK4

Gold Standard

y₁ = y₀ + (k₁+2k₂+2k₃+k₄)/6
  • Fourth-order accurate
  • Four slope evaluations
  • Matches analytical closely
  • Industry standard
y(0.1) ≈ 0.995004  |  Error: ~0
Step-by-Step

Euler Method

The simplest approach — one slope at the start of each interval

Euler — Step 1

h = 0.1, y₀=1, z₀=0
y₁
// yₙ₊₁ = yₙ + h·zₙ
y₁ = 1 + 0.1(0)
y₁ = 1.0000
z₁
// zₙ₊₁ = zₙ + h(−yₙ)
z₁ = 0 + 0.1(−1)
z₁ = −0.1
y(0.1) = 1.0000   z(0.1) = −0.1

Heun — Step 1

Predictor + Corrector
Predict
// Predictor step
y* = 1 + 0.1(0) = 1
z* = 0 + 0.1(−1) = −0.1
Correct
// Corrector step
y₁ = 1 + 0.05(0 − 0.1)
y₁ = 0.9950
y(0.1) = 0.9950   z(0.1) = −0.1
Runge-Kutta 4th Order

RK4 — Full Derivation

Four weighted slope evaluations for fourth-order accuracy

RK4 k-values (for y)

y₀=1, z₀=0, h=0.1
k₁
// k₁ = h·z₀
k₁ = 0.1 × 0 = 0
k₂
// k₂ = h·(z₀ + l₁/2)
k₂ = 0.1 × (−0.05) = −0.005
k₃
// k₃ = h·(z₀ + l₂/2)
k₃ = 0.1 × (−0.05) = −0.005
k₄
// k₄ = h·(z₀ + l₃)
k₄ = 0.1 × (−0.1) = −0.01
Result
// y₁ = y₀ + (k₁+2k₂+2k₃+k₄)/6
y₁ = 1 + (0 − 0.01 − 0.01 − 0.01)/6
y₁ ≈ 0.995004
y(0.1) ≈ 0.995004 — matches cos(0.1) exactly
l-values (for z)
// l₁ = h·(−y₀)
l₁ = 0.1 × (−1) = −0.1

// l₂ = h·(−(y₀ + k₁/2))
l₂ = −0.1

// l₃ = h·(−(y₀ + k₂/2))
l₃ = −0.09975

// l₄ = h·(−(y₀ + k₃))
l₄ = −0.0995

Conclusion

Euler's method is the simplest but least accurate. Heun's and the Midpoint method improve accuracy significantly with a predictor-corrector approach.

RK4 gives a result almost identical to the exact analytical solution — making it the method of choice for engineering simulations, robotics, vibration analysis, control systems, and dynamic modelling.
