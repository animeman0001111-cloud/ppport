Chapter 04 · Approximation

Numerical
Methods

dy/dx = x + y,  y(0) = 1
Problem Setup

Given Information

Find y(0.1) using four numerical methods with h = 0.1

dy/dx = x + y
y(0) = 1
h = 0.1
y(0.1)
Numerical Techniques

Four Approaches Compared

From simple to precise — each method improves on accuracy

Euler Method

Method 01

The simplest one-step method — uses only the slope at the current point to project forward. Fast to compute, but accumulates error over multiple steps.

  • 01Compute f(x₀, y₀) = f(0, 1) = 0 + 1 = 1
  • 02Apply formula: y₁ = y₀ + h·f(x₀, y₀)
  • 03y₁ = 1 + (0.1)(1) = 1.1000
y(0.1) = 1.1000
// Formula
yn+1 = yₙ + h·f(xₙ, yₙ)

// Calculation
f(0, 1) = 0 + 1 = 1
y₁ = 1 + (0.1)(1)
y₁ = 1.1000

Heun Method (Improved Euler)

Method 02

A predictor-corrector scheme that averages the slopes at the start and end of the interval — reducing error significantly compared to Euler.

  • 01Predictor: y* = 1 + 0.1(1) = 1.1
  • 02Slopes: f(0,1) = 1, f(0.1, 1.1) = 1.2
  • 03Corrector: y₁ = 1 + (0.1/2)(1 + 1.2) = 1.1100
y(0.1) = 1.1100
// Predictor
y* = yₙ + h·f(xₙ, yₙ)
y* = 1 + 0.1(1) = 1.1

// Corrector
y₁ = yₙ + h/2 [f(xₙ,yₙ) + f(xₙ₊₁,y*)]
y₁ = 1 + 0.05(1 + 1.2)
y₁ = 1.1100

Midpoint Method

Method 03

Uses the slope evaluated at the interval midpoint — a second-order estimate that intuitively centres the derivative within the step.

  • 01x_mid = 0.05, y_mid = 1 + (0.05)(1) = 1.05
  • 02f(0.05, 1.05) = 0.05 + 1.05 = 1.10
  • 03y₁ = 1 + (0.1)(1.10) = 1.1100
y(0.1) = 1.1100
// Midpoint values
x_mid = xₙ + h/2 = 0.05
y_mid = yₙ + (h/2)·f(xₙ,yₙ) = 1.05

// Final step
f(0.05, 1.05) = 1.10
y₁ = 1 + (0.1)(1.10) = 1.1100

Runge-Kutta 4th Order — RK4 ★

Method 04

The gold-standard numerical ODE solver. Combines four slope estimates with a weighted average — achieves fourth-order accuracy with each step.

  • k₁h·f(0, 1) = 0.1000
  • k₂h·f(0.05, 1.05) = 0.1100
  • k₃h·f(0.05, 1.055) = 0.1105
  • k₄h·f(0.1, 1.1105) = 0.12105
  • ansy₁ = 1 + (1/6)[k₁ + 2k₂ + 2k₃ + k₄] = 1.11034
y(0.1) = 1.11034
k₁ = h·f(xₙ, yₙ)
k₂ = h·f(xₙ+h/2, yₙ+k₁/2)
k₃ = h·f(xₙ+h/2, yₙ+k₂/2)
k₄ = h·f(xₙ+h, yₙ+k₃)

// Weighted sum
y₁ = yₙ + (1/6)(k₁+2k₂+2k₃+k₄)

k₁=0.1000 k₂=0.1100
k₃=0.1105 k₄=0.12105
y₁ = 1.11034
Summary

Results Comparison

All four methods applied to the same problem

Method Approach Order y(0.1)
Euler Single slope at start 1st order 1.1000
Heun Predictor-corrector 2nd order 1.1100
Midpoint Midpoint slope estimate 2nd order 1.1100
RK4 ★ Four-stage weighted average 4th order 1.11034

Conclusion

The Euler Method is the simplest but least accurate — a useful teaching tool and rough estimate, but insufficient for engineering-grade problems.

Heun and Midpoint Methods both provide significantly better approximations by incorporating additional slope information, both converging to 1.1100.

The Runge-Kutta Fourth Order Method (RK4) gives the most accurate result at 1.11034 and is widely used in engineering, robotics, simulations, and control systems.
