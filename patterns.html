Type 01

Separable Differential Equations

Variables can be separated and integrated independently

Definition
dy/dx = g(x) h(y)
Separate variables and integrate both sides independently:
dy / h(y) = g(x) dx
  • The curve rises slowly at first
  • Growth becomes faster as x increases
  • The rate of change continuously increases
  • The solution remains smooth and continuous

Solved Example

Separable · dy/dx = xy
Given
// Problem
dy/dx = xy
// Separate variables
Step 1
dy/y = x dx
Step 2
// Integrate both sides
∫(1/y) dy = ∫x dx
ln y = x²/2 + C
Step 3
// Take exponential
y = e^(x²/2 + C)
y = Ce^(x²/2)
y = Ce^(x²/2)
Type 02

Linear Differential Equations

Solved with the integrating factor method

General Form
dy/dx + P·y = Q
where P and Q are constants or functions of x. The integrating factor converts it into an exact derivative.
Integrating Factor
IF = e^(∫P dx)
Multiplying by the integrating factor transforms dy/dx + Py = Q into d/dx(y · IF) — which integrates directly.
  • e^(−x) term decreases with increasing x
  • e^x term grows rapidly with increasing x
  • Solution eventually behaves like e^x/2
  • All solution curves approach y = e^x/2 as x → ∞

Solved Example

Linear · dy/dx + y = eˣ
Given
// P = 1, Q = eˣ
dy/dx + y = e^x
Step 1
// Integrating factor
IF = e^(∫1 dx) = eˣ
Step 2
// Multiply by IF
eˣ(dy/dx) + eˣy = e^(2x)
d/dx(y·eˣ) = e^(2x)
Step 3
// Integrate both sides
y·eˣ = e^(2x)/2 + C
Step 4
// Divide by eˣ
y = eˣ/2 + Ce^(−x)
y = eˣ/2 + Ce^(−x)
Comparison

Analytical vs Numerical Methods

Choosing the right approach for the problem at hand

Property Analytical Methods Numerical Methods
Solution type Exact Approximate
Method used Integration Iterative calculations
Accuracy More accurate Depends on step size
Best suited for Simpler equations Complex equations
Output form Closed-form answer Numerical values

Conclusion

Analytical methods provide exact mathematical solutions and are preferred for simpler equations. Numerical methods provide approximate solutions when analytical methods become difficult or impossible to apply. Among numerical techniques, RK4 gives results that are extremely close to the exact analytical solution.
